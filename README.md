# ISBIS 2027 website

Save-the-date landing page for ISBIS 2027, 7–9 July 2027, hosted by the University of Pretoria.

- `index.html` page content
- `style.css` colours, fonts and layout (colour variables are at the top)
- `script.js` the "Coming soon" pop-up
- `assets/` images and logos

Anything marked `data-soon="Name"` shows the "Coming soon" pop-up. To open a real page later, create the page, change `href="#"` to its file name and delete `data-soon`.
